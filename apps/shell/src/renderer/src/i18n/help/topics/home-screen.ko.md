# 홈 화면: 파일이 있는 곳

홈은 GenOffice의 시작 페이지입니다. 가운데에 파일 목록과 빠른 생성 카드, 창 하단에는 독, 그 뒤로 바탕 화면과 아이콘이 펼쳐집니다.

![홈 화면](img/home-screen.png)

## 독

- **최근 사용**: 최근에 연 파일입니다. 각 줄에는 시간이 찍힙니다 — 오늘, 어제, 또는 날짜.
- **즐겨찾기**: 즐겨찾기한 파일입니다. 파일 줄에 포인터를 올려 별표를 누르면 등록하거나 해제할 수 있습니다. **⋯ 메뉴**의 **그룹으로 이동**으로 별표 파일을 이름 붙은 그룹으로 정리할 수 있습니다. 별표 보기는 그룹별로 걸러 봅니다.
- **AI에게 질문**: 지식 베이스 패널 — 별표 표시한 파일에 질문하고 출처가 붙은 답변을 받습니다(아래 참고).
- **Genspark Projects**: Genspark 계정으로 로그인하면 웹의 Genspark AI로 만든 프로젝트가 표시됩니다. 누르면 브라우저에서 편집을 계속할 수 있습니다. 검색, 시간순 정렬, 새로 고침, 더 불러오기를 지원합니다.
- **폴더**: 루트는 바탕 화면에 놓입니다. 빈 곳을 마우스 오른쪽 버튼으로 클릭해 **폴더를 바탕 화면에 추가…** 하고, 루트 아이콘을 오른쪽 클릭하면 바탕 화면에서 뺄 수 있습니다(디스크의 폴더는 건드리지 않습니다). 루트는 자체 보기로 열리며 탐색·하위 폴더 만들기·이름 바꾸기·이동은 그 안에서 합니다. 파일 관리자에서 끌어 온 파일은 별칭으로 고정됩니다.

창 하단의 독은 macOS 방식의 실행 패널입니다. 포인터 아래에서 아이콘이 커지고, 현재 보기에 점이 붙으며, 그룹 안에서는 끌어 순서를 바꾸고 오른쪽 클릭으로 메뉴를 엽니다. 설정 → Dock에서 확대를 끄거나 아이콘 크기를 바꾸거나 독을 자동으로 숨길 수 있습니다(아래 가장자리에 올리면 다시 나타남). 바탕 화면에는 빠른 기록용 할 일 카드도 있어 손잡이로 옮길 수 있고 위치는 기억됩니다.
여기에는 휴지통 항목이 없습니다. 삭제한 파일은 시스템 휴지통으로 가며, 되돌리는 일은 OS가 처리합니다.

## 파일 목록

각 줄에는 아이콘, 파일 이름, 수정 시각 등이 표시됩니다. 줄의 **⋯ 메뉴**에는 다음 항목이 있습니다.
### 여러 파일 한 번에

행의 체크박스를 켜거나 ⌘/ctrl 클릭으로 선택을 모읍니다. 머리글의 체크박스는 지금 목록에 있는 것을 전부 선택하고, 목록 위의 표시줄이 몇 개가 선택되었는지(**{n}개 선택됨**) 알려 주며, 선택 전체에 **폴더로 이동…** 과 **파일 삭제** 를 제공합니다. 여러 파일을 선택한 상태로 폴더 보기의 폴더 행에 끌어다 놓을 수도 있습니다.

## 빠른 시작 카드

목록 위의 카드로 한 번에 새 문서를 만들 수 있습니다. 카드를 누르면 그 종류의 파일이 만들어지고 해당 편집기가 열리니 바로 쓰기 시작할 수 있습니다. AI가 초안을 쓰게 할 수도 있습니다(각 편집기 리본에 **AI 버튼**, 선택 후 컨텍스트 메뉴에 **AI 수정 요청**이 있습니다).

새 파일은 현재 있는 폴더 보기에 만들어집니다. 폴더를 열어 두지 않았으면 기본 폴더에 들어갑니다.

각 카드의 역할:
> 팁: 메뉴의 파일 ▸ 새로 만들기에서도 같은 종류의 문서를 만들 수 있습니다(⌘N/Ctrl+N의 기본값은 텍스트 문서). 파일을 창으로 끌어다 놓으면 그대로 열립니다.

## 지식 베이스에 질문하기

- 먼저 파일에 별표를 표시하세요(앱이 읽을 수 있는 형식이면 무엇이든). 패널 머리글에 개수가 표시되고, 비어 있으면 별표를 먼저 표시하라는 안내가 나옵니다.
- 답변은 출처 파일을 밝힙니다. 인용을 클릭하면 해당 편집기에서 파일이 열립니다.
- Genspark 로그인이 필요합니다. 대화는 메모리에만 있습니다 — 앱을 닫으면 끝납니다.
- 검색은 홈 검색과 같은 로컬 색인을 사용합니다. 사라진 파일은 자동으로 대상에서 빠집니다.
- 그룹은 별표 목록 정리용일 뿐입니다 — 지식 베이스는 항상 별표 표시된 모든 파일을 대상으로 합니다.

## 클라우드 프로젝트(Genspark Projects)

- 처음 쓰려면 Genspark 계정으로 로그인해야 합니다(기기 코드 방식: GenOffice가 코드를 보여 주고 브라우저에서 로그인을 마칩니다).
- 프로젝트 목록은 웹과 동기화됩니다. "브라우저에서 열기"로 이동해 편집을 계속할 수 있습니다.
- 로그인하지 않아도 로컬 기능에는 아무 영향이 없습니다.
