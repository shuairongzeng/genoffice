# Der Startbildschirm: wo Ihre Dateien liegen

Die Startseite ist GenOffices Startseite: der Desktop mit Ihren Symbolen und das Dock am unteren Fensterrand, Dateilisten und Schnellerstellungskarten in der Mitte.

![Der Startbildschirm](img/home-screen.png)

## Das Dock

- **Zuletzt verwendet**: die zuletzt geöffneten Dateien. Jede Zeile trägt ihren Zeitpunkt — heute, gestern oder das Datum.
- **Favoriten**: die von Ihnen mit einem Stern versehenen Dateien. Fahren Sie über eine Dateizeile und klicken Sie auf den Stern, um sie hinzuzufügen oder zu entfernen. **In Gruppe verschieben** im ⋯-Menü sortiert markierte Dateien in benannte Gruppen; die Markierungs-Ansicht filtert danach.
- **Ask AI**: das Wissensbasis-Panel — stellen Sie Fragen und erhalten Sie Antworten mit Quellen aus Ihren markierten Dateien (siehe unten).
- **Genspark Projects**: nach der Anmeldung an Ihrem Genspark-Konto werden die im Web mit Genspark AI erstellten Projekte angezeigt; klicken Sie auf eines, um die Bearbeitung im Browser fortzusetzen. Suche, Sortierung nach Zeit, Aktualisierung und Nachladen werden unterstützt.
- **Ordner**: Die Wurzeln leben auf dem Desktop. Klicken Sie mit der rechten Maustaste auf den leeren Desktop für **Ordner zum Desktop hinzufügen…**; ein Rechtsklick auf das Symbol einer Wurzel nimmt sie vom Desktop (der Ordner auf der Festplatte wird nie angetastet). Eine Wurzel öffnet sich als eigene Ansicht — durchsuchen, Unterordner anlegen, umbenennen und verschieben geht von dort. Hineingezogene Dateien werden als Aliase angeheftet.

Das Dock am unteren Fensterrand ist der Starter im macOS-Stil: Symbole vergrößern sich unter dem Zeiger, ein Punkt markiert die aktuelle Ansicht, zum Neuanordnen innerhalb einer Gruppe ziehen, Rechtsklick für das Menü. Einstellungen → Dock schaltet die Vergrößerung aus, ändert die Symbolgröße oder blendet das Dock aus (über den unteren Rand wieder hervorrufen). Den Zettel der Schnellaufgaben-Karte verschieben Sie an seinem Griff; die Position bleibt erhalten.
Hier gibt es keinen Eintrag für den Papierkorb. Gelöschte Dateien landen im Papierkorb des Systems, und sie wiederherzustellen ist Sache des Betriebssystems.

## Die Dateiliste

Jede Zeile zeigt ein Symbol, den Dateinamen, die Änderungszeit und mehr. Das **⋯-Menü** der Zeile bietet:
### Mehrere Dateien auf einmal

Haken Sie das Kontrollkästchen einer Zeile an oder klicken Sie mit ⌘/Strg, um eine Auswahl zusammenzustellen; das Kontrollkästchen in der Kopfzeile wählt alles aus, was gerade aufgeführt ist, und eine Leiste über der Liste meldet (**{n} ausgewählt**), wie viele ausgewählt sind, und bietet **In Ordner verschieben…** sowie **Dateien löschen** für die ganze Auswahl. Sie können eine Mehrfachauswahl auch auf eine Ordnerzeile der Ordneransicht ziehen.

## Schnellstart-Karten

Die Karten über den Listen erzeugen in einem Schritt ein neues Dokument. Ein Klick auf eine Karte erzeugt eine Datei dieses Typs und öffnet den passenden Editor — Sie legen sofort los oder lassen die KI einen Entwurf schreiben (jeder Editor hat eine **KI-Schaltfläche** im Menüband und **KI fragen** im Kontextmenü der Auswahl).

Die neue Datei landet in der Ordneransicht, in der Sie sich befinden; außerhalb jedes Ordners geht sie in den Standardordner.

Was die einzelnen Karten tun:
> Tipp: Datei ▸ Neu in der Menüleiste erzeugt dieselben Dokumenttypen (⌘N/Ctrl+N erzeugt standardmäßig ein Textdokument); eine ins Fenster gezogene Datei wird direkt geöffnet.

## Fragen Sie Ihre Wissensbasis

- Markieren Sie zuerst Dateien (jeden Typ, den die App liest); die Kopfzeile des Panels zählt den Bestand, und eine leere Wissensbasis bittet Sie, erst etwas zu markieren.
- Antworten nennen die Herkunftsdateien; ein Klick auf eine Quelle öffnet die Datei in ihrem Editor.
- Erfordert die Anmeldung bei Genspark. Die Unterhaltung lebt nur im Speicher — das Schließen der App beendet sie.
- Die Suche läuft über den lokalen Dateiindex wie die Start-Suche; verschwundene Dateien fallen still aus dem Bestand.
- Gruppen ordnen nur die Markierungsliste — die Wissensbasis umfasst immer alle markierten Dateien.

## Cloud-Projekte (Genspark Projects)

- Für die erste Nutzung ist eine Anmeldung an Ihrem Genspark-Konto nötig (Gerätecode-Verfahren: GenOffice zeigt einen Code, Sie schließen die Anmeldung im Browser ab).
- Die Projektliste wird mit dem Web synchronisiert; „In Browser öffnen“ führt dorthin, um weiterzuarbeiten.
- Ohne Anmeldung ist keine der lokalen Funktionen beeinträchtigt.
