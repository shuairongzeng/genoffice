# ホーム画面：ファイルの置き場所

ホームは GenOffice のスタートページです。中央にファイル一覧とクイック作成カード、画面下部にはドック、その奥にデスクトップとアイコンが広がります。

![ホーム画面](img/home-screen.png)

## ドック

- **最近使用**：最近開いたファイルです。各行には時刻が付きます — 今日、昨日、または日付。
- **お気に入り**：お気に入りに登録したファイルです。ファイル行にポインターを合わせて星マークをクリックすると、登録と解除ができます。 「⋯」メニューの **グループへ移動** でスター付きファイルを名前付きグループに整理できます。スター表示はグループで絞り込めます。
- **AI に質問**：ナレッジベースパネル — スター付きファイルに質問し、出典付きの回答が得られます（下記参照）。
- **Genspark Projects**：Genspark アカウントでサインインすると、Web 版の Genspark AI で作成したプロジェクトが表示されます。クリックしてブラウザーで編集を続けられます。検索、時期順の並べ替え、更新、さらに読み込むにも対応しています。
- **フォルダー**: ルートはデスクトップに置かれます。空き領域を右クリックして **フォルダーをデスクトップに追加…**、ルートのアイコンを右クリックするとデスクトップから外せます（ディスク上のフォルダーは一切変更されません）。ルートは専用のビューとして開き、閲覧・サブフォルダー作成・名前変更・移動はそこで行います。ファイルマネージャーからドラッグしたファイルはエイリアスとして置かれます。

画面下部のドックは macOS 流のランチャーです。ポインタの下でアイコンが拡大し、現在のビューに点が付き、グループ内ではドラッグで並べ替え、右クリックでメニューが開きます。設定 → Dock で拡大の無効化、アイコンサイズの変更、ドックの自動的に隠す（下端にポインタを合わせると戻る）ができます。デスクトップにはクイック入力のToDoカードもあり、取っ手でドラッグでき、位置は記憶されます。
ここにはゴミ箱の項目はありません。削除したファイルはシステムのごみ箱に入り、元に戻すのは OS の仕事です。

## ファイル一覧

各行にはアイコン、ファイル名、更新時刻などが表示されます。行の **⋯ メニュー** には次の項目があります。
### 複数のファイルをまとめて

行のチェックボックスをオンにするか、⌘/ctrl クリックで選択範囲を作れます。ヘッダーのチェックボックスは現在表示されているものをすべて選び、一覧の上のバーが選択件数（**{n} 件選択中**）を表示し、選択全体に対して **フォルダーに移動…** と **ファイルを削除** を使えます。複数選択したものをフォルダービューのフォルダー行へドラッグすることもできます。

## 検索

上部の検索ボックスは 2 種類をまとめて検索します。
## クイックスタートのカード

一覧の上にあるカードから、1 ステップで新規文書を作れます。カードをクリックすると、その種類のファイルが作成されて対応するエディターが開くので、すぐに書き始められます。AI に下書きさせることもできます（各エディターのリボンに **AI ボタン**、選択後のコンテキストメニューに **AI に修正依頼** があります）。

新しいファイルは今いるフォルダービューに作られます。フォルダーを開いていない場合は既定のフォルダーに入ります。

各カードの内容：
> ヒント：メニューの ファイル ▸ 新規作成 でも同じ種類の文書を作れます（⌘N/Ctrl+N の既定はテキスト文書です）。ファイルをウィンドウにドラッグすると、そのまま開きます。

## ナレッジベースに質問

- まずファイルにスターを付けます（アプリが読める形式なら何でも）。パネルのヘッダーに件数が表示され、空ならスターを付けるよう案内があります。
- 回答は出典ファイルを示します。引用をクリックするとそのエディターでファイルが開きます。
- Genspark へのサインインが必要です。会話はメモリ上のみ — アプリを閉じると終了します。
- 検索はホーム検索と同じローカル索引を使います。存在しなくなったファイルは自動的に対象から外れます。
- グループはスター一覧の整理用です — ナレッジベースは常にすべてのスター付きファイルを対象にします。

## クラウドプロジェクト（Genspark Projects）

- 初めて使うときは Genspark アカウントへのサインインが必要です（デバイスコード方式：GenOffice がコードを表示し、ブラウザーでログインを完了します）。
- プロジェクト一覧は Web 版と同期します。「ブラウザーで開く」で移動して編集を続けられるようになります。
- サインインしていない場合も、ローカル機能のいずれにも影響しません。
