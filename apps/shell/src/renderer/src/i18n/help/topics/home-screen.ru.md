# Главный экран: где хранятся ваши файлы

«Главная» — стартовая страница GenOffice: рабочий стол с вашими значками и док у нижнего края окна, списки файлов и карточки быстрого создания в центре.

![Главный экран](img/home-screen.png)

## Док

- **Недавние**: файлы, которые вы открывали недавно. В каждой строке проставлено время — сегодня, вчера или дата.
- **Избранное**: файлы, которым вы поставили звёздочку. Наведите курсор на строку файла и нажмите на звёздочку, чтобы добавить или убрать. **Переместить в группу** в меню ⋯ раскладывает файлы со звёздочкой по именованным группам; вид «Со звёздочкой» фильтруется по ним.
- **Ask AI**: панель базы знаний — задавайте вопросы и получайте ответы со ссылками на файлы со звёздочкой (см. ниже).
- **Genspark Projects**: после входа в аккаунт Genspark показывает проекты, созданные вами с Genspark AI в вебе; нажмите на проект, чтобы продолжить редактирование в браузере. Доступны поиск, сортировка по времени, обновление и догрузка.
- **Папки**: корни живут на рабочем столе. Правый клик по пустому столу — **Добавить папку на рабочий стол…**; правый клик по значку корня убирает его со стола (папка на диске не трогается). Корень открывается как отдельный вид: обзор, создание подпапок, переименование и перемещение — оттуда. Перетащенные из файлового менеджера файлы закрепляются как псевдонимы.

Док у нижнего края — панель запуска в стиле macOS: значки увеличиваются под указателем, точка отмечает текущий вид, перетаскивайте для перестановки внутри группы, правый клик открывает меню. Настройки → Док отключает увеличение, меняет размер значков или скрывает док (наведите на нижний край, чтобы вернуть). На рабочем столе живёт и карточка быстрых заметок-дел — двигайте её за ручку, позиция запоминается.
Здесь нет пункта Корзина. Удалённые файлы попадают в системную корзину, а восстановить их — дело ОС.

## Список файлов

В каждой строке показаны значок, имя файла, время изменения и прочее. **Меню ⋯** строки предлагает:
### Сразу несколько файлов

Поставьте флажок у строки или щёлкните с ⌘/ctrl, чтобы собрать выделение; флажок в заголовке выбирает всё, что сейчас перечислено, а полоса над списком сообщает (**Выбрано: {n}**), сколько выбрано, и предлагает **Переместить в папку…** и **Удалить файлы** для всего набора. Множественное выделение можно также перетащить на строку папки в виде папок.

## Поиск

Поле поиска вверху находит сразу два вида совпадений:
## Карточки быстрого старта

Карточки над списками создают новый документ за один шаг. Нажатие на карточку создаёт файл такого типа и открывает его редактор — можно сразу писать, а можно поручить AI сделать черновик (в каждом редакторе есть **кнопка AI** на ленте и **Спросить ИИ** в контекстном меню выделения).

Новый файл попадает в тот вид папок, где вы находитесь; вне любой папки он попадает в папку по умолчанию.

Что делает каждая карточка:
> Совет: меню Файл ▸ Создать на панели меню создаёт те же типы документов (⌘N/Ctrl+N по умолчанию создаёт текстовый документ); перетаскивание файла в окно открывает его.

## Спросите свою базу знаний

- Сначала отметьте файлы звёздочкой (любой читаемый приложением тип); в шапке панели указан размер корпуса, а пустая база предложит сначала что-нибудь отметить.
- Ответы называют файлы-источники; щелчок по ссылке открывает файл в его редакторе.
- Требуется вход в Genspark. Разговор живёт только в памяти — закрытие приложения его завершает.
- Поиск идёт по локальному индексу файлов, как на «Главной»; исчезнувшие файлы тихо выпадают из корпуса.
- Группы нужны только для списка «Со звёздочкой» — база знаний всегда охватывает все файлы со звёздочкой.

## Облачные проекты (Genspark Projects)

- При первом использовании нужен вход в аккаунт Genspark (схема с кодом устройства: GenOffice показывает код, а вы завершаете вход в браузере).
- Список проектов синхронизируется с вебом; команда «Открыть в браузере» переходит туда, чтобы продолжить работу.
- Отказ от входа не влияет ни на одну из локальных возможностей.
